# Step 8: what a plugin can reach

Each lab plugin tries the same things and reports what happened. A page is served on 127.0.0.1:8765 for the network attempts (`index.html`, 12 bytes). Generated by `scripts/step08_trust.py`.

## Item plugin (viewer's QML engine)

`--set layers=curious-item`

```
qml: curious item: viewer singletons: Lab renderer is rhi · Timeline mode is live · 0 health streams
qml: curious item: called Timeline.pause(): mode is now live
qml: curious item: network: read 12 bytes
qml: curious item: 2 s later: Timeline mode is paused · 11 health streams
```

## Script plugin, QML entry (own QML engine)

`--set layers=curious-script`

```
qml: curious script: viewer singletons: Lab is Viewer/Lab
qml: curious script: viewer modules: AppOptions is qp::AppOptions(0x56017aed8ca0)
qml: curious script: network: blocked (status 0)
qml: curious script: file: pending
```

## Script plugin, JS module (own JS engine)

`--set layers=curious-js`

```
js: curious js: viewer singletons: blocked (ReferenceError: Qt is not defined)
js: curious js: network: blocked (ReferenceError: XMLHttpRequest is not defined)
js: curious js: host objects: print, console
```
